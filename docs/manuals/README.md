# Manuals

Device manuals for LSPRimaging Acquisition, mirroring sLSPR acq's `docs/manuals/`
convention (see `apps/sLSPR/acq/docs/manuals/`).

- `cri-varispec-lctf-manual.pdf` — CRi VariSpec LCTF User's Manual (Doc Part No.
  MD15474 Rev. D, August 2010). Covers the serial command set used by
  `spikes/lspri_acq_phase0/illumination_probe.py` (the Phase 0 spike, in the
  umbrella repo) and, eventually, the real `variSpec_lctf.py` driver described in
  `docs/architecture/general/lspri_acq_architecture_and_shared_shell_plan.md` §6.2
  (also in the umbrella repo).

Moved here from `spikes/lspri_acq_phase0/docs/manuals/` on 2026-08-08, once this app
was scaffolded as its own repo/submodule, per that folder's own README note.
